## Overview

This fork / branch from Blackduck Detect enables meson scans for Blackduck. Unfortunately Blackduck did not want to merge this, as they consider Meson not to be a package manager and don't want to use the meson-info as dependency information. This is unfortunate, because dependency tracking is important. 

For C/C++ they recommend using https://community.blackduck.com/s/article/Using-the-Black-Duck-C-CPP-Tool instead.
